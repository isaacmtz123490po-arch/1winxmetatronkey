# Mi Aplicación - Servidor Node.js con Express

Servidor HTTP sencillo que escucha en `0.0.0.0:3000` y responde con un saludo y la IP del cliente.

## Instalación y ejecución

```bash
cd mi-aplicacion
npm install
npm start
```

Luego abre en el navegador:
- `http://localhost:3000`
- o `http://<tu_direccion_IP>:3000`

## Archivos

- `app.js` — código del servidor
- `package.json` — dependencias y script de inicio
