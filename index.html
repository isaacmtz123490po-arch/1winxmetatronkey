Descargar archivos de Android Googlesource

Genera un enlace para descargar todos los archivos de un repositorio como un archivo .tar.gz.

Copiar el contenido completo de un archivo

Pega la URL de un archivo de Google Source. Ábrelo en formato texto, copia la respuesta y pégala abajo; el botón la decodifica y copia el contenido original completo.

Nota: el navegador no permite que este HTML descargado lea automáticamente archivos de otro sitio. Para evitar errores o contenido cortado, copia la respuesta completa del archivo y pégala aquí. Esta opción es para archivos de texto UTF-8, no binarios.

Importante: la página principal de android.googlesource.com es un catálogo con muchos repositorios, no una carpeta única de archivos. Primero elige un repositorio y pega su URL aquí. Los repositorios grandes pueden tardar o exceder los límites del servidor.
